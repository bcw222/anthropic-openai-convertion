anthropic-openai-convertion

This endpoint speaks the OpenAI Chat Completions API and forwards to an Anthropic Messages (/v1/messages) upstream.

Point your OpenAI-compatible client's base URL at this deployment and use your Anthropic key (or whatever key your upstream expects) as the API key.

  • POST /v1/chat/completions
  • GET /v1/models

404 here is expected if you opened this in a browser.
